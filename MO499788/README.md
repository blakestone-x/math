# Sharp bounds for tree matrix entries

The largest absolute off-diagonal entry of the positive square root of a tree biadjacency Gram matrix is 1/√2. Only the two leaves of the three-vertex path attain it. For each even distance the connecting path gives the unique sharp example. The companion paper extends the comparison to positive real powers and proves the change in behavior at half the distance.
