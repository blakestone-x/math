# Fixed points and coverage in six greedy decimal sequences

Every positive integer appears in Angelini and Hasler's A218468. For every $k\ge0$ the term at index $2\cdot10^k$ is exactly $2\cdot10^k$, as Hans Havermann predicted in 2013. In fact the entire prefix through that index consists of the integers from 1 through the index, and a terminal interval of length $(1-o(1))10^k$ is fixed pointwise. [Manuscript](decimal-permutations.pdf) · [LaTeX](decimal-permutations.tex) · [Original problem](https://oeis.org/A218468)

## Reproduction

- The eight base cases generate every term through index 20,000,000 with exact integer arithmetic. Compile `c++ -std=c++17 -O2 decimal_check.cpp -o /tmp/decimal-check` and run `/tmp/decimal-check`. Each reported prefix has no repeated value, maximum equal to its length, and last term equal to its length. The paper bounds the jumps for every larger exponent. [C++ verifier](decimal_check.cpp) · [Certificate](fixed-prefixes.csv)
- A direct least-unused implementation uses a fresh search on every turn. It reproduces all 484 displayed source terms across the six original entries and checks both alternate starting conventions. Run `python3 check_prefixes.py`. [Independent implementations and reference terms](check_prefixes.py) · [Expected output](source-checks.txt)
- The formal files use Lean 4.33.1 and the dependencies pinned by Left to Solve at formal-conjectures revision `9097e2f90e66d2f6244209cb1c07f7120d17ec53`. The four modules in `OMAStatements/` reproduce the published proposed targets, each with the site's required placeholder for human review. Build those modules first when checking the proofs. The proofs of the claims in the table use no placeholder and the three complete board results passed the site's proof and axiom checker. The remaining formal lemma shows that an injective least-unused sequence reaches any target allowed at arbitrarily late turns.
