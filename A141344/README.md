# A141344 · Mathar’s recurrence and the signs of the terms

Blake Stone · Proof developed with OpenAI Codex.

A first-order differential identity for Paul Barry’s generating function proves R. J. Mathar’s 2012 three-step recurrence for every $n\ge3$. All terms through index 16 are positive. From index 17 onward, odd-index terms are negative and even-index terms are positive.
