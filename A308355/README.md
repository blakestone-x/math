# The exact stable prefix of the partition-length rows

Blake Stone · Proof developed with OpenAI Codex.

For the row listing the numbers of parts in the partitions of N in decreasing lexicographic order, the common prefix with the limiting row has length A025065(N). This gives Kimberling’s prefix formula with an explicit row convention. The entry A308355 writes A025065(n+1), which applies when row n contains the partitions of n+1. At N = 3 the prefix has length 2.
